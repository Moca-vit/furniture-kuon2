# 久遠 KUON トップページ（全幅案）

「本文は細く、写真と動画は全幅」のデザイン案です。ブランド・数値・実績・写真は、すべて仮（架空）の内容です。

## VS Code で開く
1. VS Code で、このフォルダ（kuon-site）を開く（ファイル → フォルダーを開く）
2. 拡張機能「Live Server」をインストール
3. index.html を右クリック → 「Open with Live Server」

## フォルダ構成
- index.html … ページ本体（HTML・CSS・JSが1ファイル）
- assets/ … 動画（mp4）と画像（webp・jpg）

## 編集の目安
- 色・余白・文字サイズ … index.html 先頭の `:root{ ... }`
- 文章 … `<main>` の中
- 動画の再生ルール … 末尾の `<script>`（PCはホバー、スマホは画面中央で一度だけ再生）
- 椅子の列の流れる速さ … `var BASE=36;`（1秒あたりに流れるpx）、早送りの倍率は `boost=8`、流れる向きは `var DEFAULT=-1;`（-1で左、1で右）
- 写真・動画の差し替え … assets/ に同じ名前で上書き（動画は10MB以内・音なしが目安）

## 注意
- 写真と動画の出どころ・ライセンスは、公開前に必ず確認してください
- 実在の施主名・実績ではないため、公開する場合は「イメージ」「仮」の表記を実際の内容に差し替えてください
- 「イメージ」表記の写真・映像は、実際の納入先・修理事例の素材に差し替えるときに、ラベル（`<span class="tag">IMAGE</span>`）と注記も合わせて外してください
- ブランドフィルムは、いまは静止画のスライドショー（準備中）です。動画ができたら `#story-slides` を動画に差し替えます

## 画像クリックで拡大表示（ライトボックス）
- 対象：コレクションの静止画（ダイニング2枚、ラウンジチェア、ソファ、椅子シリーズ）。動画は対象外です。
- 閉じ方：背景の暗い部分をクリック／右上の×／Escキー。
- 触る場所（index.html内を「ライトボックス」で検索）：
  - CSS：`#lb`（背景の暗さは `rgba(28,28,28,.9)` の最後の数字、ホバー拡大の倍率は `.zm:hover img` の `scale(1.04)`）
  - HTML：`<div id="lb">…</div>`（拡大表示の枠）
  - JS：`ライトボックス` と書かれたブロック（開く・閉じる処理）
- 拡大対象を増やすには、画像を `<div class="zm">…</div>` で包むだけです（椅子シリーズは `.rail` の中に置けば自動で対象）。
- メニューの並びはページ内の並びと同じ（コレクション→ストーリー）です。

## WORKS（住まいの中で、育つ家具。）の映像：拡大して再生
- 小さい画面：PCはホバー、スマホは画面中央で、今まで通り軽いプレビュー再生（音なし）。
- クリック／タップ：映像が元の位置から前面に広がり、プレビューの続きから再生します（音はオフ。右下のスピーカーでオン）。
- 3本まとめて見られます：下の ‹ › ボタン、キーボードの ← →、スマホは左右スワイプ。下スワイプ／背景クリック／×／Escで閉じます。
- 拡大用の映像は別ファイル（house-hd.mp4・house2-hd.mp4・house3-hd.mp4、各0.5〜1.2MB）。クリックした時に初めて読み込まれるので、ページは重くなりません。
- 触る場所（index.html内で `data-lb` を検索）：映像を増やすときは、`<div class="pv" data-lb="works" ...>` と `<video data-src=... data-hd=拡大用ファイル data-ar=縦横比>`（縦長は0.5625、横長は1.7778）を同じ形で追加します。

## 追加ページ（index.html と同じフォルダに置いてください）
- `contact.html`：お問い合わせフォーム（カタログ請求／お見積り依頼／修理／ご来店／設計者・不動産会社／その他）。`contact.html?type=catalog` のようにリンクすると、その用件が最初から選ばれます（catalog / estimate / repair / visit / trade / other）。名前とメールアドレスが必須。送信は見本のため、実際には送られません（本番では、フォーム送信サービスやサーバーにつなぎます）。
- `trade.html`：設計者・不動産会社向けの「準備中」ページ（椅子が組み上がるアニメーション）。
- `sub.css`：上の2ページ共通のスタイル。
- トップページの各ボタンのリンク先：カタログ請求→contact.html?type=catalog／お見積り依頼→contact.html?type=estimate／ご来店予約（お問い合わせ欄内）→contact.html?type=visit（仮）／設計者向けページへ→trade.html／ご相談の流れへ→ページ内の「ご相談から、納品まで」。

## 追加ページ（第2弾）
- `visit.html`：ご来店予約（ショールーム紹介＋予約フォーム）。必須は、お名前・メール・第1希望日。水曜（定休日）や過去の日にちは選べないようにチェックします。トップの「ご来店予約」ボタンは、すべてここへ。
- `company.html`：会社概要（仮）。`guide.html`：ご購入ガイド（仮）。
- `sub.js`：サブページ共通の動き（読み進みの線、目次の現在地、FAQ開閉、スマホ下の固定ボタン）。`sub.css` と一緒に置いてください。

## 第3弾の変更
- 日にち入力：`data-date` を付けた入力欄をクリックすると、カレンダーが開きます（`sub.js` の「日にち選択」）。定休日の曜日は `data-closed="3"`（0=日〜6=土、3=水）、予約できる期間は `data-max="180"`（日数）で変えられます。
- 先頭へ戻る矢印は、サブページすべてで `sub.js` が自動で追加します。ページを開いたときは必ず一番上から表示します。
- 「樹種・仕上げの見本」の写真：`assets/sample-wood-480.webp`（スマホ・PC標準）／`sample-wood-800.webp`（高精細画面用）。

## ページを開いたときの動き（追加）
各HTMLの先頭（head内）の小さなスクリプトで「必ず一番上から、ふわっと表示」しています。
消したい場合は、各HTMLの `<script>` 内「pg-in」の部分と、sub.css 末尾の pg-in の2行を削除してください。
